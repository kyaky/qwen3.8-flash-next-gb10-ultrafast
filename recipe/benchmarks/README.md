# Benchmark tools

`decode_bench.py` is the upstream-derived standalone decoder benchmark. `bench_agent.py` runs the coding benchmark with `--prompts recipe/benchmarks/prompts.example.json`. `bench_copy_streams.py` measures the copy-heavy 1-8 stream curve with three rounds per count; `--streams 5 6 7 8` selects the extension levels. It builds three public copy tasks and a long shared prefix by default; `--prompts` accepts a JSON workload with `system`, `tools` and three `tasks` entries. `measure_equal_length.py` remains available for equal-length measurements. The method is documented in the repository docs; per-round records for the current release ship under [docs/benchmarks](../../docs/benchmarks/). Include prompt shape, cache state, acceptance, image digest and repetition count with published results.
